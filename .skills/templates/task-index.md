# 任务索引

本文件是已持久化任务的编号与生命周期总览。合同读 spec，当前操作状态读 task plan，执行、验证和下一步读 progress；本文件中的状态摘要只是一份可重建投影，不反向覆盖这些权威记录。

## 索引策略

| 字段 | 值 |
| --- | --- |
| task_index_mode | `<required / disabled>` |
| 编号策略 | `<项目定义>` |
| 编号基线 | `<当前最大编号；下一个建议编号>` |
| 正式任务分配 | `先创建 spec/micro-spec，再占用编号并登记` |
| 候选待办 | `不占正式编号` |
| spec / micro-spec 路径 | `<path>` |
| 最近对账 | `<date + evidence>` |

`required` 时，所有持久化 spec/micro-spec 必须登记；内联 query、`zero` 和内联 micro-spec 不登记。`disabled` 时，`PROJECT_RULES.md` 中的任务索引路径必须为 `N/A`。

## 状态摘要转换

| 当前状态 | 允许进入 | 最小证据 |
| --- | --- | --- |
| `待办` | `规划中 / 取消` | 已创建权威任务文档 |
| `规划中` | `待批准 / 待验证 / 暂停 / 取消` | 计划或文档任务验收入口 |
| `待批准` | `执行中 / 规划中 / 暂停 / 取消` | checkpoint 与批准状态 |
| `执行中` | `待验证 / 规划中 / 暂停 / 取消` | progress 执行记录 |
| `待验证` | `待手工验收 / 待提交 / 已收口 / 执行中 / 暂停 / 取消` | 验证结果或失败锚点 |
| `待手工验收` | `待提交 / 已收口 / 执行中 / 暂停 / 取消` | 外部验收结果 |
| `待提交` | `已收口 / 执行中 / 暂停 / 取消` | 提交门禁仅在 Done Contract 要求时使用 |
| `暂停` | `进入暂停前的非终态 / 取消` | 阻塞解除或取消决定 |
| `已收口` | `规划中` | 显式重开原因和新范围 |
| `取消` | `N/A` | 继续处理时建立新任务 |

`待手工验收` 和 `待提交` 可按项目策略跳过。`暂停` 恢复时只能返回有来源锚点的暂停前非终态。`取代` 不是生命周期状态：被取代的未收口任务使用 `取消`，文档状态使用 `已被取代`，并链接替代任务。任何跳转都必须引用 spec、task plan 或 progress；索引与权威记录冲突时，将任务汇总中的文档状态标记为 `需同步`，不得反向覆盖权威记录。

文档状态只使用：`已同步 / 需同步 / 已被取代 / 缺失`。

## 维护规则

- 新增候选前查重；候选不占正式编号。
- 晋升时先确认目标与验收，再在一个逻辑事务内创建任务文档、分配编号并登记任务、移除候选。
- 将候选来源写入正式任务的“来源/关联任务”。
- 创建、升级、批准、执行、验证、暂停、取消、重开、取代和收口时同步状态摘要。
- 编号冲突、文档缺失或事务中断时停止执行，扫描任务文档与索引后修复。
- 跨项目主任务只在工作区为 `required` 时登记；参与项目只为本级 `required` 的持久化任务登记本地索引并建立双向链接。`disabled` 层级和内联 micro-spec 使用 `N/A`，由父级 spec 直接链接持久化任务文档或实际证据。
