# 自定义调整模块

此目录用于保存可复用的“技能组合和项目 override”规则。它不存放目标项目的业务事实；业务事实应进入 `.skills/project/`。

项目私有技能放在 `.skills/project-skills/` 或项目既有技能目录；本目录只保存通用能力之间的组合和路由补丁。

## 已提供模块

| 模块 | 用途 |
| --- | --- |
| `sdd-grill-bridge.md` | 将 Grill 作为复杂 SDD 任务的需求提纯前置，而非执行替代品 |
| `matt-pocock-bridge.md` | 将原型、条件 TDD、困难诊断、冲突解决、深模块设计和领域建模接入 SDD；架构体检仅保留显式入口 |

`workflows/grill-me.md` 是包内、面向现有代码库的需求提纯工作流；全局 `$grill-me` 是无代码库的独立访谈入口，不因名称相同而互相替代。

## 新增自定义模块的最低要求

每个模块必须写清：触发条件、输入、输出、失败处理、检查点、反模式、项目 override 的放置位置。不要只写“按需使用”或把外部工具名当成流程定义。
