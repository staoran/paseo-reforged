## 读取规则

- 陌生项目、跨模块任务、调用链定位、架构改动或跨项目任务先读总图。
- 当前特性存在专用 map 时，先读专用 map，再按其中路径回读源码。
- 修改入口、模块边界、数据流、依赖、生成链路或项目结构后扫描是否漂移。
- map 中发现但不在当前范围内的问题，登记为候选待办，不顺手实现。
