## 1. 目标与完成契约

- 当前理解：Web/Electron 的自绘右键菜单打开后，用户应能直接在另一个右键目标上再次右键；不应先左键关闭旧菜单，也不应因全屏浮层命中而弹出系统菜单。
- 核心目标：在共享 Web `ContextMenu` 边界修复事件命中与单一 owner，保留既有业务菜单定义、Native 长按/bottom sheet 和 Electron 原生终端/文本菜单。
- Done Contract：sidebar 的 workspace -> project、workspace tabs 的 A -> B 均可由同一次第二次右键关闭旧菜单并打开新菜单；diff 文件行的右键旁路采用相同行为且 kebab 不回归；菜单外左键关闭菜单但不触发下层目标；目标 Playwright、typecheck 与 lint 提供证据。

## 2. 范围与事实

- 范围内：共享 `ContextMenu` 的 Web 渲染与 dismiss 事件；sidebar、workspace tabs 的连续右键回归；diff 文件行复用现有文件动作并对齐同一右键 primitive。
- 范围外：把业务菜单改写为 Electron 原生 `Menu`、重做菜单视觉、修改 Native 长按/底部面板、改变 terminal 与普通文本/链接的原生菜单。
- 当前任务单元：Web 自绘菜单的连续右键切换；`parent spec=N/A`。
- 轻量评估：`足够小`；根因集中于共享 primitive，diff 仅移除已确认的 Dropdown 右键旁路。若需要新增跨应用菜单框架或公共契约，则暂停并升级深度。
- 已确认事实：`components/ui/context-menu.tsx` 在 Web 仍使用 React Native `Modal` 和全屏 backdrop；第二次右键命中旧菜单 backdrop，目标 `ContextMenuTrigger` 收不到事件，且该事件 `defaultPrevented=false`。
- 已确认事实：sidebar 与 workspace tabs 使用共享 `ContextMenu`；`git/diff-pane.tsx` 的右键则控制 `FileActionsMenu` 的 `DropdownMenu`，存在同类全屏 backdrop 风险；terminal 与普通文本/链接使用 Electron 原生菜单，不在本任务根因内。
- 风险与未知：Web 菜外左键必须继续只关闭菜单而不误触下层动作；菜单内交互、Escape/focus、overlay 相对层级不能回归；diff 的连续右键需在共享 primitive GREEN 后按第二个纵向切片验证。
- 重开增量：只为已实现的 Web 菜外左键消费行为补 Playwright 回归；不改变 Native、菜单视觉或其他业务菜单。
