## 1. 目标与完成契约

- 当前理解：新会话首条消息触发的自动工作区标题，应使用用户在应用设置中选择的有效界面语言
- 核心目标：将已解析的 App locale 随首个 Agent 上下文传入 daemon，并写入标题生成提示词
- Done Contract：新客户端发送 locale 后，生成器提示词明确要求 title 使用该语言；无该字段的旧客户端请求仍可解析并维持原行为；定向测试覆盖两项

## 2. 范围与事实

- 范围内：`FirstAgentContext` 可选 locale 字段、App 新建工作区入口、server 生成器提示词与定向测试
- 范围外：持久化全局语言设置、既有标题重生成、项目 `paseo.json` 行为、分支名语言
- 当前任务单元：足够小
- 已确认事实：应用语言目前只存于客户端；标题生成在 daemon 异步运行；标题/分支生成共享 `FirstAgentContext`
- 风险与未知：远程旧 daemon 不理解新字段时协议 object 默认剥离未知字段；为保持双向兼容，新字段必须可选
