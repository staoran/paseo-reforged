## 1. 目标与完成契约

- 当前理解：`diffStat` 是某个 checkout 相对基线的总变化，不是当前会话或 Agent 的修改量；同一 `cwd` 的多个 Workspace 重复显示相同数字没有信息增量。
- 核心目标：取消在侧边栏 Workspace 行和 Workspace 页面顶部显示 checkout 修改数量；不转移到 Project 行，不增加显示开关。
- Done Contract：所有 Project 分组 Workspace 行、Pinned 行、Status 行和 Workspace 顶部都不显示 checkout `+N/-N`；Project 行不新增统计，Settings 不新增开关；行尾菜单与源码控制按钮仍可用；hover card、源码控制面板、文件 diff 和归档判断仍可消费底层 `diffStat`。

## 2. 范围与事实

- 范围内：三处 sidebar Workspace `DiffStat` 及其 action slot 可见性条件、Workspace 顶部 `DiffStat`、聚焦测试。
- 范围外：Project 行、Settings/i18n、共享 `DiffStat` 组件、hover card、源码控制面板与文件 diff、会话级修改量、server/protocol/store 数据链和归档判断。
- 当前任务单元：删除导航界面中的 checkout 总修改数量，保留数据与其他上下文消费者；`parent spec=N/A`。
- 轻量评估：`standard`；跨四个 UI 渲染文件，但只删除视觉调用与收紧现有 slot 条件。
- 已确认侧边栏渲染点：`sidebar-workspace-list.tsx:714-730`、`sidebar/sidebar-workspace-row.tsx:385-401`、`sidebar/sidebar-status-list.tsx:693-758`。
- 已确认耦合：`diffStat` 参与 `shouldRenderActionSlot/visible/showBase`；只删 `<DiffStat>` 会留下空占位。
- 指标语义事实：daemon 按 `workspace.cwd` 调用 `getCheckoutShortstat`，以当前 checkout 与解析基线的 merge-base 计算 tracked shortstat，并加入未跟踪文本行；该链路没有会话或 Agent ID，不能解释为当前会话贡献。
- 顶部位置事实：`workspace-screen.tsx:3526-3531` 当前在非移动端源码控制图标旁显示 `workspaceDescriptor.diffStat`；最新方案保留图标和面板入口，仅移除数字。
- 数据链事实：相同数据还供 `workspace-hover-card.tsx`、源码控制和 `worktree-archive-warning.ts` 使用，不能因展示位置改动删除。
- 产品决策：分支/checkout 数据不归属单个会话，也不适合在可包含多个 checkout 的 Project 行聚合；因此不再为该导航统计寻找展示位置。
- 风险：三个 Workspace renderer 的 action slot 条件不同，需确保删除数字后 hover 菜单仍保留稳定占位。
