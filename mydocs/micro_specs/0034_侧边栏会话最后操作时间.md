## 1. 目标与完成契约

- 当前理解：在主侧边栏的 workspace 会话行右侧显示该会话最近一次有效活动的相对时间；中文界面呈现“刚刚”“5分钟前”“1天前”“1周前”等同类文案。
- 核心目标：复用现有 Agent 活动事实，把最近操作时间稳定投影到项目分组和状态分组共用的侧边栏行，同时保持操作按钮、快捷键徽标和窄宽度布局可用。
- Done Contract：未归档根 Agent 的最新 `lastActivityAt` 能到达对应侧边栏会话行；无活动时间时不显示占位；相对时间按当前 App 语言显示并随时间推进刷新；项目/状态两种分组都通过共用行内容生效；定向测试、typecheck 与 lint 通过。

## 2. 范围与事实

- 范围内：`packages/app` 的 workspace Agent 活动索引、侧边栏 workspace 投影、相对时间格式化与行内展示；必要的 locale 文案；定向单元/组件测试。
- 范围外：协议字段、daemon 行为、History 独立页面、会话排序规则、发布与提交、并行任务 `0033`。
- 当前任务单元：为侧边栏现有会话行增加最后操作相对时间。
- 轻量评估：`足够小`；数据链与共用渲染点已定位，预计为少量 App 文件和多语言资源的局部变化。
- 已确认事实：侧边栏实际渲染 `SidebarWorkspaceEntry`；项目分组和状态分组共用 `SidebarWorkspaceRowContent`；Agent 已提供 `lastActivityAt`；`WorkspaceAgentActivity` 当前只保留状态进入时间，尚未暴露最后活动时间；App 支持八种 locale，资源键由测试保持同步。
- `grilling` 结论（如使用）：`N/A`。
- 风险与未知：同一 workspace 存在多个未归档根 Agent 时应取最大 `lastActivityAt`，不能改变现有状态 bucket 的选择语义；行尾时间不得与 hover 菜单或快捷键徽标重叠；当前假设用户所说“侧边栏会话列表”指主侧边栏 workspace 行，而不是 History 独立页面。
