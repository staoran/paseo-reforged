## 1. 目标与完成契约

- 当前理解：打开会话时 Agent 历史初始化超时会进入错误态，但页面只有错误文案，没有恢复入口。
- 核心目标：在 Agent 加载错误态提供可操作的“重试”按钮，点击后重新执行当前会话加载流程。
- Done Contract：超时/加载错误态显示带 `Retry` 文案和刷新图标的按钮；点击后错误态消失并重新发起加载；既有找不到 Agent 与正常加载行为不变。由定向测试、typecheck、lint 和格式检查证明。
