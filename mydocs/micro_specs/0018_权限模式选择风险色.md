## 1. 目标与完成契约

- 当前理解：“权限选择”指 composer 的 Agent Mode 控件；其 manifest 已携带风险等级，但当前 UI 丢失了老项目的风险色。
- 核心目标：在当前响应式 toolbar/sheet/combobox 结构中恢复风险色，不回退新布局。
- Done Contract：dangerous/planning/moderate/acceptEdits 使用对应风险色，safe/未知保持 muted，自定义 `#hex` 原样使用；触发器和选项图标/文字一致；selected/hover/pressed/disabled 状态保持现状。

## 2. 范围与事实

- 范围内：Agent Mode 风险色映射、触发器 value style、combobox label style、缺失 theme token 和聚焦验证。
- 范围外：运行时 permission request card、桌面系统权限、protocol/provider manifest、控件布局重做。
- 当前任务单元：Agent Mode 视觉语义；`parent spec=N/A`。
- 轻量评估：`standard`；共享控件需要两个窄 style 直通点。
- 控件证据：`packages/app/src/composer/agent-controls/mode-control.tsx` 消费 provider mode；`packages/protocol/src/provider-manifest.ts:38` 已定义 `colorTier`。
- 根因：上游提交 `5ad6cff03` 删除 mode color treatment；后续 `8e063f0df` 将触发器迁至共享 `AgentControlTrigger`，当前 UI 只消费图标。
- 老项目参考：`E:\Code\paseo-reclaude\packages\app\src\composer\agent-controls\mode-control.tsx:74-176` 映射 dangerous=red、planning=cyan、moderate=warning、acceptEdits=merged。
- 已选方案：恢复局部 tier -> theme color 函数；`control.tsx` 只增加可选 `valueStyle`，`combobox.tsx` 只恢复可选 `labelStyle`，`theme.ts` 补仅供 mode 使用且在交互表面满足文本对比度的 light/dark accent token。
- 实现结论：风险色由纯映射函数统一解析，当前 trigger 与 combobox option 只消费解析结果；没有改变现有 compact sheet、选择或禁用交互结构。
- 风险与未知：老项目没有当前 compact sheet；本任务保持其结构，只将相同颜色直通当前值、图标和 option label。
